# CashFlow

Aplicação web de controle financeiro desenvolvida com HTML, CSS e JavaScript puro.

O projeto permite registrar entradas e saídas financeiras, visualizar saldo total em tempo real e acompanhar os gastos através de um gráfico interativo.

## Funcionalidades

- Registro de transações financeiras
- Controle de entradas e saídas
- Atualização automática do saldo total
- Histórico de transações
- Gráfico dinâmico de gastos
- Validação de formulário
- Interface responsiva
- Categorias de despesas
- Modal interativo para adicionar transações

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Chart.js
- Font Awesome

## Conceitos Aplicados

- Manipulação de DOM
- Eventos JavaScript
- Responsividade
- Flexbox & Grid
- Formatação de moeda com `toLocaleString`
- Validação de formulários
- Estruturação de layout
- Atualização dinâmica de interface

## Objetivo do Projeto

O objetivo do projeto foi praticar desenvolvimento front-end moderno utilizando JavaScript puro, criando uma aplicação interativa e visualmente organizada.
